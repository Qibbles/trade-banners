# Trade Banners

Create your own game trade banners. Choose your game, add what you're buying and selling, and copy the generated banner into Discord or anywhere you trade.

Currently supports **Ultima Online: Outlands**.

## Features
- Separate **Buying** and **Selling** banners
- Item icons and material colors from the game's art
- Tick items on/off, drag to reorder, optional subtitle and footer
- Copy as an image with one click
- Lists are saved in your browser (localStorage)
